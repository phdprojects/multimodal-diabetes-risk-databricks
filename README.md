# 🚀 Multimodal Healthcare AI: Previsão de Risco de Diabetes

Este projeto demonstra a construção de um pipeline multimodal em **PySpark** no **Databricks**, combinando dados tabulares clínicos e exames de Raio-X de tórax.

## 📌 Destaques do Pipeline
- **Tratamento de Dados Clínicos:** Imputação preditiva de nulos/zeros biologicamente impossíveis.
- **Arquitetura Multimodal:** Fusão de embeddings visuais de Raios-X com variáveis numéricas.
- **Sensibilidade Clínica:** Foco em Recall > 95% para minimizar Falsos Negativos.
- **Explicabilidade:** Mapeamento visual com Grad-CAM e SHAP.
